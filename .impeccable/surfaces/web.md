# Company site and merchant workspace

## Scope

Replace the visible identity with Avenra. The homepage uses Persuade mode; the workspace uses Operate mode. The user authorized a new brand and UX/UI for this repository. The design launcher is unavailable; this session builds directly from the written direction and verifies the implementation in desktop and mobile browser captures.

## Direction

Payments as a clear, branching path. The original A mark is a rising pair of strokes joined by a horizontal path. The homepage pairs an oversized, confident headline with a precise interactive routing diagram. Evergreen provides composure, warm ivory provides reading clarity, and lime marks deliberate action. Dense but calm tables and forms carry the same identity into everyday operations.

## First viewport

Full-width evergreen navigation; a generous ivory hero with the headline “Every payment. A better path.”; two functional calls to action; a routing visual that shows the selected processor. No fabricated commercial results, customer logos, or compliance proof.

## Visitor path

Understand the routing mechanism, explore the live demonstration workspace, and find the repository/API documentation. The workspace must make the demo status visible and support filtering, details, export, routing changes, and connector management.

## Risk and verification

The workspace is a new demonstration frontend rather than a production replacement of the separate upstream Control Center. Local settings and example transactions are labelled as demo data. Verify the new routes, controls, data states, keyboard access, and responsive composition without claiming backend integration.
